# Simon Says Game

A classic, interactive implementation of the nostalgic **Simon Says** memory game built using vanilla JavaScript, HTML5, and CSS3. Test and improve your sequence-matching memory skills!

👤 **Author:** H. Kumar ([@Git-H-kumar](https://github.com/Git-H-kumar) | [LinkedIn](https://www.linkedin.com/in/h-kumar-))

---

## Features

* **Dynamic Sequence Generation:** The game progressively adds steps to the pattern, increasing difficulty as you level up.
* **Visual & Audio Feedback:** Flash animations and interactive button states correspond to each color block in the sequence.
* **Score Tracking:** Keeps track of your current level and high score during the session.
* **Responsive Design:** Clean layout optimized for both desktop and mobile screens.

---

## Tech Stack

* **Markup:** HTML5
* **Styling:** CSS3 (Flexbox, Grid, Custom Transitions)
* **Logic:** Vanilla JavaScript (ES6+, DOM Manipulation, Event Handling)
